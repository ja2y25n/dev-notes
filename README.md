# 📁 Portfolio — 김재연

공공 SI/SM 개발 경험을 정리한 포트폴리오입니다.
모든 사례는 **보안상 시스템 실명·테이블·엔드포인트·수집 대상 등을 일반화**하여 기술 관점만 담았습니다.

---

## 👤 강점
- **완주하는 실전형** — 차세대 오픈 장애대응부터 레거시 전환을 기획~개발까지 완주
- **설계·분석 중심** — 역설계, 마이그레이션 설계, 기능분해(FP) 등 시스템 전체를 구조화
- **융합 프로필** — 법학 + 공공 도메인 + 개발 + AI(재학). 요구사항 해석·문서·커뮤니케이션에 강점

## 🧗 어려움을 이겨낸 방식
1. 비전공·늦은 시작의 불리함을, 담당도 아닌 차세대 전환을 스스로 맡아 "완주 실적"으로 뒤집음
2. 외부 매체 개편으로 반복 실패하던 수집기를, 셀렉터 땜질이 아닌 구조적 fallback 설계로 해결
3. SM(운영) 계약의 좁은 범위를 신규 개발·보안 조치·데이터 품질까지 스스로 확장

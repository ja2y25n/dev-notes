# dev-notes

공공 SI·SM 개발 실무에서 겪은 **트러블슈팅 · 레거시 분석 · 데이터 수집 자동화** 기록을 정리한 저장소입니다.

전자정부프레임워크(eGovFrame) 기반 공공 웹 개발자로서, 단순 버그 수정을 넘어 **업무 흐름과 데이터 운영 원칙을 이해해야 풀리는 문제**를 다룬 사례를 담았습니다.

> 모든 사례는 실제 업무를 바탕으로 하되, 공공기관 내부 정보(실제 URL·기관명·테이블·컬럼명·구체 수치)는 추상화했습니다.

## 다루는 주제

- **크롤러 회복탄력성** — 사이트 개편(SPA 전환)에도 버티는 fallback 설계
- **트랜잭션·PK 처리** — "로그는 정상인데 DB 미반영" 유형 장애
- **업무 CASCADE / 논리삭제** — 코드가 아니라 행정 업무 규칙을 이해해야 풀리는 결함
- **레거시 분석(FP)** — 노후 시스템을 기능점수 기준으로 전수 분해

## About

비전공(법학) 출신으로 개발에 입문해, "업무 흐름을 문서로 정리하고 코드로 연결하는" 강점을 살려 일합니다.

*장애는 기술 구현보다 업무 흐름의 이해에서 갈린다.*

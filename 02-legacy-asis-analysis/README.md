# 02. 레거시 AS-IS 분석 — 리버스 엔지니어링

요구사항정의서가 없는 레거시 시스템을 소스 전수조사로 역분석하여 차세대 전환 요구사항의 기준선을 직접 구성한 작업입니다.

## 방법론 (4단계)
1. **인벤토리** — 화면·기능·데이터·배치 전수 목록화, 화면설계서와 상호 매핑
2. **갭분석** — 레거시 구조를 전자정부 표준 모델과 대조, 대응 유형 분류
3. **연동조사** — 기능분해도 밖의 외부연동·인증·배치·보안 리스크 발굴, 위험도 산정
4. **재배치** — Controller/Service/Mapper/JSP 계층 재배치 기준 수립

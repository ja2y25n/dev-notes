# 05. 정책여론수렴 시스템 — 기능개발·개선

여론 데이터 수집·분석 공공 시스템의 운영(SM)을 하며 지속적으로 수행한 기능개발·화면구현·쿼리개선·수집확대 이력입니다.

- **기능 개발** — 공휴일 API 연동·업무외 접근 통제, 입력 밸리데이션, 검색조건 확장
- **화면·시각화** — 매체별 비교분석 그래프 확대, 데이터 가공(treedata) → 시각화
- **쿼리·데이터** — 부처별 언급량 기간별 조회
- **수집 확대** — 플랫폼별 수집기 게시판 추가

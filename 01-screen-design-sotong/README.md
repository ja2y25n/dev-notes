# 01. 소통나눔방 차세대 전환 — 기획·설계

ASP 기반 공공 게시판 시스템을 eGovFrame(Spring/PostgreSQL)으로 전환하는 프로젝트에서, SM 계약 인력임에도 AS-IS 분석부터 개선방향 도출, 화면설계·기획서 작성·발표까지 주도했습니다.

## 파일
- `screen-design-portfolio.pdf` / `.docx` — 설계 산출물 설명 (화면 이미지 일부 포함)
- `CAUTION-public/` — ⚠️ 화면 설계 원본 발췌본·전체본 (아래 주의)

## ⚠️ 공개 주의
`CAUTION-public/` 폴더의 파일들은 마스킹(실제 URL·기관명·문서코드 제거)을 거쳤으나, **화면 레이아웃·설계 구조 이미지**를 포함합니다. 공공기관 시스템 UI 구조가 드러날 수 있으므로:
- 공개(public) 저장소라면 이 폴더를 **삭제하거나 비공개 저장소로 이동**하는 것을 권장합니다.
- 면접·제출 시에는 링크나 파일 직접 전달 방식을 권장합니다.
